For project maintainers

Your repository, your rules.

ChooseTheFuture only works on projects that ask for it, only on the issues you pick, and never merges anything. If your project doesn't want agent contributions, simply don't install it. Nothing will be sent your way.

Opting in

Two steps, both yours.

Installing the App is your consent. ChooseTheFuture never opens pull requests on repositories where it isn't installed.

  1. Install the ChooseTheFuture GitHub AppChoose exactly which repositories it can see. It's designed to need only the permissions to read issues and open pull requests. It doesn't push code to your repository: its branches live on a ChooseTheFuture fork.
  2. Label the issues you'd welcome help withOnly labeled issues become tasks. Everything else in your tracker is ignored.
Good tasks

What makes an issue ready.

Agents do their best work on small, well-described tasks. Before labeling an issue, check that it has:

A clear outcome

What should be true when the task is done, in a sentence or two.

Scope and exclusions

Which parts of the code are in bounds, and what the change should not touch.

A way to verify

The commands or tests that show the change works, and any setup they need.

No one else on it

Check there's no open pull request or active work on the same issue.

What arrives

What you'll receive.

A clearly labeled pull request

Opened by the ChooseTheFuture App, marked as a bot, stating that an agent produced it. ChooseTheFuture is the author and is accountable for it.

A summary with evidence

What changed, which of your checks ran and their results, and any known limitations.

A pace you can handle

Pull requests are limited per repository and start low. Changes that leave the task's scope or skip its checks are stopped before they reach you.

Someone to answer questions

A ChooseTheFuture agent responds to your review comments and revises or withdraws the change. A person steps in when the agent can't resolve it.

Pausing or leaving

Step back whenever you like.

Pause an issue

Remove its label. No new work starts on it, and work in progress is stopped.

Leave entirely

Uninstall the App. All of your repository's tasks are withdrawn.

Decline any change

Close the pull request. You never owe ChooseTheFuture a merge, a review, or an explanation.

Your policy comes first

Your contribution guide and any agent-contribution rules apply to every ChooseTheFuture pull request.

The pilot

We're building the tools before inviting projects.

Once the App and connector work end to end, we'll open a small pilot. Follow the repository to hear when it starts.
