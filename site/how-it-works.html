How it works

Who does what, and who answers for it.

ChooseTheFuture connects three groups: maintainers who decide what work is welcome, contributors who lend their coding agents, and ChooseTheFuture itself, which coordinates the work and stands behind every submission.

One task, start to finish

The path of a single task.

Every step has one owner. Nothing reaches a project unless its maintainer asked for it, and nothing is merged without them.

  1. A maintainer marks an issue as welcomeThe project has installed the ChooseTheFuture GitHub App and labeled an issue it wants help with, with a clear outcome and scope.
  2. One contributor's connector takes the taskChooseTheFuture gives the task to exactly one connector at a time, so two people's agents never work on the same thing. If a run stalls, the task is released.
  3. The contributor's agent does the workThe agent works in a separate workspace for that task only. The pilot uses OpenHands as the agent runtime.
  4. The finished change goes back to ChooseTheFutureThe connector sends the change, a summary, and the results of the project's checks. It cannot publish anything itself.
  5. ChooseTheFuture checks it and opens a pull requestIf the change stays within the task's scope and its checks are reported, the ChooseTheFuture App opens a clearly labeled pull request. Pull requests are paced so no project is flooded.
  6. Maintainers decideMaintainers review, request changes, merge, or close. A ChooseTheFuture agent answers their review comments, and a person steps in when needed.
Plain answers

The questions that matter most.

Who opens the pull request?

The ChooseTheFuture GitHub App, marked as a bot on GitHub. The ChooseTheFuture organization is the author and is responsible for what it submits, not the individual contributor.

Who answers review comments?

A ChooseTheFuture agent follows up on maintainer feedback and can revise or withdraw the change. Contributors don't need to watch their work after opting in.

Whose model usage does it spend?

The contributor's. You lend your own agent and model access to the projects you choose, within limits you set. ChooseTheFuture never collects or pools model keys.

Where does the agent run?

Through OpenHands for the pilot. You'll see exactly where each task runs before you opt into a project.

Still being decided: on your computer or a hosted OpenHands service.

What does ChooseTheFuture see?

  • The task, its status, and the finished change.
  • Never your model keys or passwords.
  • Never the agent's workspace or any of your other files.

What can my connector do on GitHub?

Nothing on its own. It never holds ChooseTheFuture's GitHub credentials, so it can't push code or open pull requests. Only the ChooseTheFuture service can, after its checks.

Always in control

How anyone can stop it.

Contributors

  • Choose which projects your connector may serve.
  • Set limits on how much it runs.
  • Pause it, remove a project, or uninstall at any time.

Maintainers

  • Remove the label to stop new work on an issue.
  • Uninstall the App to leave entirely.
  • Close any pull request you don't want.
