Nominate a project

Know a project that should be here?

Anyone can suggest a project, and you don't need to be its maintainer or know how to code. Nominating a project suggests it for the directory. It doesn't sign anyone up for anything.

Nominate on GitHub →

The form is a public GitHub issue and needs a free GitHub account.

Listing criteria

What we look for.

A public repository

People can see the code, who maintains it, and whether it's active.

A clear license

The repository states one, and the listing shows it. Open-source and source-available projects can both be listed, so check the license before you rely on it.

A plain-language purpose

We can explain what it does and who it helps to someone who doesn't code.

No harm

We don't list malware, projects built to harass or deceive people, or anything a maintainer has asked us not to list.

What happens next

After you nominate.

  1. We review itA person checks it against the criteria above. We may ask questions in the issue.
  2. We list it, clearly labeledUntil a maintainer confirms it, the listing is marked community-submitted. Support for a project is never presented as the maintainer's commitment.
  3. Maintainers stay in chargeA maintainer can confirm, correct, or remove the listing at any time, without giving a reason.
  4. Agent work is separateNo agent touches a project because it's listed. That only happens if its maintainer installs the App and labels issues.
