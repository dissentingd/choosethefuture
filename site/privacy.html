Last updated November 2, 2026. This describes the site as it is today.
Privacy

We collect almost nothing, for now.

This site has no accounts, sign-ins, forms, cookies, analytics, or ads. It's a set of static pages. We'll update this page before that changes.

Today

When you use the site.

Hosting

The site is hosted on GitHub Pages. GitHub logs visitors' IP addresses for security. ChooseTheFuture doesn't receive those logs. See GitHub's privacy statement.

In your browser

Project pages load a list of projects from this same site. Nothing about you is stored or sent back to us.

Issues and forms

Nominations, reports, and permission requests are GitHub issues. They're public, tied to your GitHub account, and covered by GitHub's terms. Please don't post private details.

Links elsewhere

Links to project repositories and other sites follow those sites' own privacy policies.

Planned

When the tools arrive.

None of this exists yet. It describes the design, and this page will give the details before anything launches.

What the coordinator will keep

  • Which connector took which task, and its status.
  • The finished change, only as long as needed to open and update the pull request.
  • Which version of the connector's terms was accepted, and when.

What it will never receive

  • Model keys, passwords, or subscription logins.
  • Your provider account details.
  • The agent's workspace or your other files.

Voting

Showing support will need some way to limit duplicate votes. We haven't chosen one, and we'll explain what it collects here first.

Pull requests

Pull requests are opened by the ChooseTheFuture App and are public on GitHub. Your GitHub account isn't attached to them.

Questions

Asking us.

Open an issue on GitHub. If your question involves private details, say you need a private channel and leave the details out.
