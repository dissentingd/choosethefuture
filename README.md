# ChooseTheFuture

ChooseTheFuture helps people direct spare AI coding-agent capacity toward open-source projects they want to see built.

## How it works

1. People browse projects and vote for the goals they want to see advanced.
2. Each project shares current priorities and contribution guidance.
3. Supporters copy a project-specific prompt into the coding agent they already use.
4. They review the agent's work and submit contributions through the project's normal process.

ChooseTheFuture helps people decide where to contribute. Contributors work in their own environments, and project maintainers retain control of their repositories and review process.

## Project status

Early concept and planning. The initial site, hosting, and contribution workflows are not yet implemented.

## Planned first steps

- Define the smallest useful project directory and project page.
- Pilot with a few open-source projects and manually curated goals.
- Add clear voting, task status, and copyable agent prompts.
- Later, publish with GitHub Actions and GitHub Pages after DNS is configured.
